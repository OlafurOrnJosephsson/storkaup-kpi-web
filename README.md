# storkaup-kpi-web

Framendaskrár KPI-síðna Stórkaups, afgreiddar í gegnum jsDelivr á föstum
commit-pinnum (`cdn.jsdelivr.net/gh/<repo>@<sha>/Webflow/<skrá>`).

Aðeins það sem vafrinn sækir hvort eð er. Kóðinn á bak við (gagnainnlestur,
SQL, rekstur) er í lokuðu repoi. Engin leyndarmál eiga heima hér.
